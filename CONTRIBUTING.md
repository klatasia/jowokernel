# Contributing to JowoKernel

Thank you for your interest in contributing to JowoKernel!

## Guidelines
1. **Originality**: JowoKernel is built from scratch. Do not copy code from Linux, Fuchsia/Zircon, or any other project. All contributions must be your own original work.
2. **Style**: Use the established coding style (C++17 for kernel, C for basic bindings). Tab indentation, clear variable names, and extensive comments are required.
3. **Architecture**: Keep microkernel principles in mind. No drivers in the kernel!
4. **Sign-off**: All commits must include a `Signed-off-by` line.

## Process
Submit a pull request via the JowoKernel Gerrit/GitLab instance for review by the maintainers.
