## 1. Tujuan Milestone

M3.3 bertujuan untuk mengaktifkan **transisi privilege Ring 3 ↔ Ring 0** yang stabil melalui syscall interface. Ini adalah fondasi untuk seluruh userspace application development.

### Objectives

- [x] Implementasi syscall handler di kernel
- [x] Transisi Ring 3 → Ring 0 menggunakan `swapgs`
- [x] Transisi Ring 0 → Ring 3 menggunakan `sysretq`
- [x] Validasi pointer userspace dengan `copy_from_user()`
- [x] Implementasi Process Exit (`SYS_EXIT`)
- [x] ELF loader untuk userspace binaries
- [ ] Runtime validation di QEMU (PENDING)

### 3.2 swapgs Implementation

**File**: `kernel/arch/x86/interrupts.S`

#### Entry Path (Ring 3 → Ring 0)

```asm
isr_common:
    /* Cek apakah interrupt dari User Mode (Ring 3) */
    testq $3, CS_OFFSET_IN_BASE_FRAME(%rsp)  /* CS ada di RSP + 24 */
    jz .L_kernel_interrupt
    swapgs                               /* Load Kernel GS Base */
.L_kernel_interrupt:
    /* Save registers... */
```

#### Return Path (Ring 0 → Ring 3)

```asm
    /* Restore registers (pop)... */
    
    /* Cek apakah kembali ke User Mode (Ring 3) */
    testq $3, CS_OFFSET_IN_BASE_FRAME(%rsp)  /* Setelah pop, CS di RSP + 24 */
    jz .L_return_to_kernel
    swapgs                               /* Kembalikan User GS Base */
.L_return_to_kernel:
    iretq
```

#### Syscall Entry (Always from Ring 3)

```asm
syscall_entry:
    swapgs                               /* Wajib: kernel entry */
    
    movq %rsp, %gs:0                     /* Save user RSP */
    movq %gs:8, %rsp                     /* Load kernel RSP */
    
    /* Push interrupt frame... */
    /* ... */
    
    call handle_syscall
    
    /* Restore dan return */
    popq %rcx        /* User RIP */
    popq %r11        /* User RFLAGS */
    popq %rsp        /* User RSP */
    swapgs                               /* Kembalikan user GS */
    sysretq
```

### 3.3 copy_from_user() Implementation

**File**: `kernel/syscalls/syscalls.cpp`

```cpp
static bool copy_from_user(void* dest, const void* user_src, u64 len) {
    if (len == 0) return true;
    
    u64 start = (u64)user_src;
    u64 end = start + len;
    
    // User space pada x86_64: < 0xFFFF800000000000
    // Kernel space: >= 0xFFFF800000000000
    if (start >= 0xFFFF800000000000ULL || 
        end > 0xFFFF800000000000ULL || 
        end < start) {
        return false;  // EFAULT
    }
    
    // Copy byte-by-byte (dalam kernel mode, SMAP assumed disabled)
    char* d = (char*)dest;
    const char* s = (const char*)user_src;
    for (u64 i = 0; i < len; i++) {
        d[i] = s[i];
    }
    return true;
}
```

### 3.4 SYS_WRITE Handler

```cpp
case SYS_WRITE: {
    const char* user_buf = reinterpret_cast<const char*>(arg2);
    u64 count = arg3;
    
    if (count > 0x10000) count = 0x10000;  // Max chunk
    
    if (arg1 == 1 || arg1 == 2) {  // stdout or stderr
        char kbuf[256];
        u64 bytes_written = 0;
        while (bytes_written < count) {
            u64 chunk = count - bytes_written;
            if (chunk > sizeof(kbuf) - 1) 
                chunk = sizeof(kbuf) - 1;
            
            if (!copy_from_user(kbuf, user_buf + bytes_written, chunk)) {
                return (u64)-14;  // EFAULT
            }
            kbuf[chunk] = '\0';
            serial_puts(kbuf);
            bytes_written += chunk;
        }
    }
    return count;
}
```

### 3.5 Process::Exit() Implementation

**File**: `kernel/kernel/process.cpp`

```cpp
void Process::Exit(int status) {
    state_ = ProcessState::ZOMBIE;
    exit_code_ = status;

    // Wake parent if waiting
    wait_queue_.WakeAll();
    
    // Close all file descriptors
    for (int i = 0; i < 256; i++) {
        if (fd_table_[i]) {
            FreeFileDescriptor(i);
        }
    }
    
    // Terminate all threads belonging to this process
    for (auto* t : threads_) {
        if (t) {
            t->SetState(ThreadState::TERMINATED);
        }
    }
}
```

## 5. Known Limitations

1. **No SMAP/SMEP** - Kernel currently accesses user memory without SMAP protection
2. **Limited syscall numbers** - Only basic syscalls implemented
3. **No argument validation** - Minimal validation beyond pointer check
4. **Single-process model** - Only one userspace process at a time
5. **No signal handling** - Signals not yet implemented
